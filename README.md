# Осенняя ферма (первая версия)

Браузерная 3D-игра, спокойный симулятор огорода: крот-огородник сажает, поливает и собирает урожай на маленьком острове. Монохромная оранжевая палитра, пиксельная постобработка.

**Играть:** https://p4rzifalus.github.io/osennyaya-ferma/

> Основная работа сейчас идёт над продолжением. Вторая версия (цвет, ночь, нечисть, енот) лежит в соседней папке [`osennyaya-ferma-2`](../osennyaya-ferma-2).

## Как запустить у себя

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173. Можно запустить и в превью Claude: конфигурация «ogorod» в `.claude/launch.json`.

- `npm run build` — собрать игру в папку `dist`
- `npm run preview` — посмотреть собранную версию

Публикация автоматическая: после `git push` в `main` GitHub сам собирает игру и выкладывает её на Pages (`.github/workflows/`).

## Что где лежит

| Файл | За что отвечает |
|---|---|
| `src/config.js` | **Все игровые числа:** скорость роста, цены, семена, стиль (`STYLE`). Менять можно самому |
| `src/main.js` | Запуск игры и главный цикл |
| `src/scene.js` | Сцена, камера, свет |
| `src/island.js`, `src/decor.js` | Остров, дом, дерево с качелями, камни |
| `src/grid.js`, `src/garden.js` | Клетки огорода и грядки |
| `src/plants.js` | Растения по стадиям роста |
| `src/mole.js` | Персонаж-крот |
| `src/input.js` | Клавиатура, мышь и тапы |
| `src/ui.js` | Панель инструментов и магазин |
| `src/postfx.js` | Постобработка: пиксели (а ещё отключённые режимы «выкл» и ASCII) |
| `src/save.js` | Сохранение в браузере (localStorage) и досчёт роста за время отсутствия |
| `public/fonts/` | Шрифты интерфейса |
| `CLAUDE.md` | Правила игры и стиля для Claude |
| `PLAN.md` | План по этапам |

## Стек

Three.js + Vite, без сервера: всё хранится в браузере игрока.
