# Огород (рабочее название)

Браузерная 3D-игра, спокойный симулятор огорода. Прототип для себя.
Стек: Three.js + Vite. Публикация: GitHub Pages.

## Обо мне
Я дизайнер, не разработчик. Объясняй решения простыми словами, без жаргона.
Перед каждым этапом показывай план и жди моего «ок». После рабочего шага предлагай закоммитить.

## Игра
- Изометрия, ортографическая камера, фиксированный ракурс (без вращения), зум не нужен.
- Персонаж: крот-огородник в соломенной шляпе (оригинальный персонаж, собран из простых фигур).
- Цикл: посадить семя → полить → вырастает → собрать → отнести в корзинку → монеты → купить семена в магазине.
- Прогрессия: открываются всё более интересные семена (цепочка в PLAN.md).
- Никакого давления: растения не вянут, нет таймеров-наказаний.
- Растения растут и при закрытой вкладке: при выходе сохраняем время, при входе досчитываем рост.
- Животных и крафта нет.

## Управление (гибридное)
- Клавиатура: WASD / стрелки — ходьба, пробел — действие на клетке перед персонажем, 1–4 — инструменты.
- Мышь / тап: клик по клетке — персонаж идёт туда и выполняет выбранное действие.
- Панель инструментов внизу экрана: семена, лейка, руки (собрать). Крупные кнопки — игра должна работать на телефоне.

## Визуальный стиль
- Геометрия: примитивы (кубы, цилиндры, конусы), без текстур и сложных моделей.
- Постобработка, переключается клавишей P (временно, для сравнения):
  1. выкл — чистая сцена
  2. пиксели — рендер в низком разрешении, растягивание без сглаживания
  3. ASCII — символы по яркости `.:-=+*#@`
- Палитра строго монохромная оранжевая, все цвета приводятся к ближайшему:
  `#1a0a00 #4a1c00 #8c3a00 #d9661a #ff9933 #ffd9a0`
- Панель с ползунками (lil-gui) для настройки стиля: размер пикселя, размер символа ASCII, контраст. Открывается клавишей G, в финале уберём.

## Технические правила
- Сохранение — localStorage, без сервера.
- Код разбит на понятные файлы (сцена, персонаж, грядки, постобработка, интерфейс, сохранение).
- Все игровые числа (скорость роста, цены) — в одном файле config.js, чтобы я мог менять их сам.
