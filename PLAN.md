# План прототипа

Один этап — одна сессия. Каждый этап заканчивается тем, что можно открыть в браузере и потрогать.

## Этап 0. Подготовка
- Папка проекта, CLAUDE.md и PLAN.md в корне, git.
- Vite + Three.js, запуск локального сервера.
**Готово, когда:** в браузере открывается пустая оранжевая страница.

## Этап 1. Сцена и персонаж
- Изометрическая камера, огород 8×8 клеток, домик и корзинка из кубов.
- Крот-огородник из простых фигур, ходит на WASD / стрелках.
- Клик / тап по клетке — персонаж идёт туда. Подсветка клетки под курсором.
**Готово, когда:** можно гулять по огороду клавишами и мышью.

## Этап 2. Стиль ⭐ главный
- Приведение цветов к оранжевой палитре.
- Три режима постобработки, переключение на P: выкл / пиксели / ASCII.
- Панель ползунков (G) для настройки.
- Проверка на телефоне: читается ли ASCII.
**Готово, когда:** я выбрал режим и зафиксировал значения ползунков.

## Этап 3. Грядки
- Панель инструментов внизу: семена, лейка, руки.
- Посадить → полить → растение растёт по стадиям (росток → куст → спелое).
- Собрать урожай в руки, отнести в корзинку.
**Готово, когда:** прошёл полный цикл с одной морковкой.

## Этап 4. Время и сохранение
- Скорость роста в config.js.
- Сохранение в localStorage, досчёт роста при возвращении во вкладку.
**Готово, когда:** посадил, закрыл вкладку, вернулся — выросло.

## Этап 5. Магазин и прогрессия
- Корзинка превращает урожай в монеты.
- Магазин семян, новые семена открываются по мере сбора урожая:
  морковь → редис → тыква → подсолнух → светящийся гриб (финальная диковинка).
- У каждого растения своя форма из примитивов и своё время роста.
**Готово, когда:** можно дойти до светящегося гриба.

## Этап 6. Телефон
- Адаптация интерфейса, тапы, размер кнопок, производительность.
**Готово, когда:** комфортно играется на моём телефоне.

## Этап 7. Публикация
- Сборка и выкладка на GitHub Pages.
- Убрать переключатель стилей и панель ползунков (или спрятать).
**Готово, когда:** игра открывается по ссылке с телефона.
